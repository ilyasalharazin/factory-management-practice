Factory Management System

A practical learning project to understand how different technologies work together to build a web application.

Technologies

- Python (Backend)
- Flask (Web Framework)
- HTML (Frontend)
- CSS (Styling)
- PostgreSQL (Database)
- Supabase (Database Hosting)
- GitHub (Version Control)

Project Structure

- backend: Python application
- frontend: HTML and CSS
- database: SQL scripts
- docs: Documentation
- tests: Testing files

Learning Objectives

- Database design and relationships
- Backend development
- Frontend development
- Database connectivity
- Authentication and authorization
- Row Level Security (RLS)
